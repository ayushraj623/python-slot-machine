# 🎰 Python Slot Machine

A text-based slot machine simulation built entirely in Python. 

## 🚀 Features
* **Betting System:** Allows users to deposit a starting balance and choose how much they want to bet per line.
* **Dynamic Grid:** Generates a randomized grid of symbols (e.g., 3x3) mimicking the spinning reels of a real slot machine.
* **Win Calculations:** Evaluates the rows for matching symbols and automatically calculates winnings based on dynamic multipliers.

## 📋 Prerequisites
Ensure you have Python installed on your system. You can check your version by running:
`python --version` (Requires Python 3.x)
